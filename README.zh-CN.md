# SpeakLoop · 自主英语听力与口语学习工具

[English](README.md)

SpeakLoop 是一款面向中国英语学习者的本地优先听力与口语学习软件。它把你真正感兴趣的视频变成一套可以反复执行的训练闭环：

**盲听 → 在语境中理解 → 逐句模仿 → 回听对比 → 收藏复习**。

它解决的不只是“发音不够好”。很多输入型学习者能做对听力题，却无法在自然视频里迅速切分语音、抓住意思；即便听懂了，也很难在真实交流中快速反应。SpeakLoop 的目标是同时提升听力理解、反应速度，以及对自然英语节奏的直觉。

![SpeakLoop 总览](docs/assets/speakloop-overview.png)

## 为什么做 SpeakLoop

传统听力练习经常强调找答案，却不足以训练对完整语流的理解。自己感兴趣的视频比固定教材更有动力，但它们也难以被方便地暂停、转录、反复听和模仿。

| 常见困难 | SpeakLoop 的训练方式 |
| --- | --- |
| 听见英文，却分不出词和意思 | 听写模式与逐层揭晓让你先听、后看。 |
| 能听懂题目，却跟不上自然对话 | 用完整语境中的真实句子反复播放、调速和定位。 |
| 知道表达，却无法快速说出来 | 跟读原声、循环本句，再听自己的录音与原声对比。 |
| 无法坚持固定材料 | 上传自己真正感兴趣的视频，建立私人练习库。 |

## 看看练习过程

| 先听再看 | 逐句练习 | 建立自己的输入库 |
| --- | --- | --- |
| 用**听写**和逐层揭晓，让字幕在你真正需要时才出现。 | 播放本句、循环本句、A–B 片段与录音回听，把一句话变成可重复的小练习。 | 上传自己的视频，或按口音、主题和时长建立个人定制推荐。 |
| ![盲听与逐层揭晓](docs/assets/listening-modes.svg) | ![逐句练习台](docs/assets/practice-workspace.svg) | ![个人定制推荐](docs/assets/personal-library.svg) |

顶部总览展示的是完整闭环：导入视频，带着目的盲听，只在需要时揭晓提示，再反复跟读和回听。素材库始终留在自己的电脑中。

## 功能

- 导入 MP4、WebM、MOV 等本地视频并保存在自己的资源库。
- 使用自己的 OpenAI 或智谱 AI Key 自动生成英文字幕。
- 使用 OpenAI、智谱 AI 或 DeepSeek 翻译中文字幕。
- 中英文字幕可直接编辑，修改后自动存档到对应视频。
- 支持单句播放、单句循环、2–8 秒 A–B 循环、调速与自由拖动。
- 听写模式提供逐词对照；逐层揭晓模式提供渐进提示。
- 本机录音、回听自己的声音、原声 → 我的录音 A/B 对比。
- 可选 Azure Speech 单词级发音反馈、目标口音与可用的语调反馈。
- 收藏好句，并从收藏夹跳回原视频位置。
- 借助 Codex 定时任务生成个人推荐；可选自动导入已核验直链视频，不会自动调用转写或翻译。

## 推荐使用流程

1. 选择感兴趣的视频：演讲、访谈、Vlog、纪录片，或与雅思话题相关的内容。
2. 导入视频，配置 OpenAI 或智谱 AI 后点击「AI 自动转写」。
3. 优先使用播放本句、听写模式或逐层揭晓盲听，不急着看全文字幕。
4. 需要时再翻译中文，在语境中理解表达。
5. 录下自己，连续听原声和自己的录音，重点对照节奏、停顿和重音。
6. 收藏可复用输入，在收藏夹中持续复习。

## 安装与运行

SpeakLoop 已完成 Windows 桌面版打包。安装包会内置本地运行环境与 LGPL 兼容的 FFmpeg，因此普通学习者不需要安装 Node.js，也不需要单独配置 FFmpeg。

请仅从本仓库的 **[GitHub Releases](https://github.com/belphogr/speakloop/releases)** 页面下载官方 Windows 安装包；不要从其他来源下载同名安装程序。

### Windows 桌面版

Release 发布后，普通用户按以下方式安装：

1. 只从 GitHub Releases 下载 `SpeakLoop-Setup-<版本号>.exe`。
2. 核对公布的 SHA-256 校验值与第三方声明。
3. 运行安装程序，选择安装目录；若需要桌面入口，保持「创建桌面快捷方式」启用。
4. 从桌面或开始菜单启动 SpeakLoop。视频库会独立保存在 `%APPDATA%\SpeakLoop`，不会放进安装目录。

### 源码运行（开发者）

若要参与开发或运行尚未发布的开发版本，请按[中文安装说明](docs/INSTALLATION.zh-CN.md)操作，也可查看 [English installation guide](docs/INSTALLATION.md)。源码方式需要 Windows、Node.js 18+，以及放在 `tools/ffmpeg/bin/` 下的 FFmpeg/FFprobe：

```bash
npm start
```

再在浏览器打开 <http://localhost:4173>。使用桌面安装包时不需要这一开发者流程。

### 配置 AI 服务

打开软件中的「设置 → API 设置」。

| 服务 | 用途 | 说明 |
| --- | --- | --- |
| OpenAI | 英文转写、中文翻译 | 使用自己的 API Key。 |
| 智谱 AI | 英文转写、中文翻译 | 用于短音频片段。 |
| DeepSeek | 仅中文翻译 | 不用于视频转写。 |
| Azure Speech | 可选发音评测 | 可能产生 Azure 费用。 |

Key 仅保存在当前浏览器会话，关闭页面后会清除。

## 个人定制推荐

进入「资源与记录 → 推荐设置」，选择口音、主题、视频时长和数量，复制生成的提示词，并在 Codex 为当前项目创建定时任务。任务会更新 `user-data/recommendations.json`。

若勾选「自动导入已核验的直链视频」，下次打开资源页时，尚未导入的 MP4/WebM 直链会保存到本机资源库；不会自动转写、翻译或消耗 AI API 额度。

## 隐私与本地数据

SpeakLoop 是本地 Node.js 软件，不是 GitHub Pages 静态网站。

- `video-library/` 保存导入视频和字幕记录。
- `user-data/` 保存收藏与个人推荐。
- 这两个目录已被 Git 忽略，不应上传到 GitHub。
- API Key 仅放在浏览器会话存储中。
- 只有你主动发起相应操作时，文件、文本或录音才会被发送给 AI 服务商。

## 注意事项

- 只导入你有权下载、保存和练习的视频。
- 自动推荐导入只接受公开 HTTPS 视频直链，单个文件上限为 300 MB。
- 单独打开 `public/` 静态目录无法使用导入、存档、转写和推荐接口；必须通过 `npm start` 运行本地服务。
